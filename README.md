# Café Aroma

Sitio web de una cafetería ficticia desarrollado con HTML, CSS y JavaScript.

## Páginas

- Inicio: index.html
- Menú: menu.html
- Contacto: contacto.html

- ## Instalación

1. Clona el repositorio.
2. Abre la carpeta del proyecto en Visual Studio Code.
3. Abre index.html en un navegador.
